# Public projects and research

> Explore ControlStackAI’s public agent tools, operating-system components, aerospace research, and developer libraries, with source links and explicit project maturity.

This directory contains public repositories only. A public repository does not imply production readiness or a particular license. See each project’s documentation and license for its current scope.

## Projects

### Aero Foundation

Research into aerospace-model training with checkable engineering-tool rewards. No trained model or qualification is claimed.

Status: Research and design. [Source and documentation](https://github.com/aerospace-superintelligence/aero-foundation). [Website](https://foundation.aerospace-superintelligence.com/).

### agent-installer

Agent-assisted Linux live installer with shared onboarding, identity, and Arch/NixOS adapters

Status: Public source. [Source and documentation](https://github.com/alinaos-org/agent-installer).

### alinaos-showcase

ALINA OS: an AI-native operating system. Film, tour, and architecture (source is private)

Status: Public source. [Source and documentation](https://github.com/alinaos-org/alinaos-showcase). [Website](https://alinaos.com/).

### buzz-openclaw

OpenClaw channel integration for self-hosted Buzz relays over Nostr

Status: Integration preview. [Source and documentation](https://github.com/alinaos-org/buzz-openclaw).

### Engram

Neural-memory research with a synthetic-user benchmark and baseline runners. The proposed memory architecture is not a released trained model.

Status: Research · benchmark implemented. [Source and documentation](https://github.com/alinaos-org/engram). [Website](https://alinaos-org.github.io/engram/).

### linux-voice-cockpit

A typed, headless voice control plane connecting browser audio, realtime sessions, and OpenClaw agent tools.

Status: Prototype. [Source and documentation](https://github.com/alinaos-org/linux-voice-cockpit). [Website](https://alinaos-org.github.io/linux-voice-cockpit/).

### nix-openclaw-tools

Nix packages for OpenClaw's CLI tools, used by alinaos-org/nix-openclaw (from openclaw/nix-openclaw-tools, MIT)

Status: Public source. [Source and documentation](https://github.com/alinaos-org/nix-openclaw-tools).

### openclaw-nix

Build and run current OpenClaw releases on Nix: source-built gateway, single-release package set, writable Control UI support

Status: Public source. [Source and documentation](https://github.com/alinaos-org/openclaw-nix).

### openclaw-system-agent

Resident OpenClaw Linux system agent with portable lifecycle, explicit capabilities, and Arch/NixOS adapters

Status: Public source. [Source and documentation](https://github.com/alinaos-org/openclaw-system-agent).

### agent-bank

Agent Bank platform: API, policy engine and co-signer, ledger, indexer, x402 facilitator, console, TypeScript SDK and MCP server.

Status: Pre-release · testnet only. [Source and documentation](https://github.com/bank-of-an-agent/agent-bank).

### contracts

Solidity contracts for Agent Bank: escrow, payment streams, time-lock vaults, policy hook, top-up and sweep executors (Foundry).

Status: Pre-release · testnet only. [Source and documentation](https://github.com/bank-of-an-agent/contracts).

### exit-tool

Open-source owner exit tool: withdraw everything from an Agent Bank smart account with only an RPC URL and the owner key.

Status: Pre-release · testnet only. [Source and documentation](https://github.com/bank-of-an-agent/exit-tool).

### sdk-python

Python SDK for Agent Bank: signed agent requests, payments, escrow and an x402 client for httpx.

Status: Pre-release · testnet only. [Source and documentation](https://github.com/bank-of-an-agent/sdk-python).

### ControlStackAI Dynamics

ControlStackAI Dynamics — founding-phase autonomous engineering research

Status: Founding-phase research. [Source and documentation](https://github.com/controlstackai-dynamics/controlstackai-dynamics.github.io). [Website](https://controlstackai-dynamics.github.io/).

### ControlStackAI Silicon

ControlStackAI silicon — founding-phase autonomous engineering research

Status: Founding-phase research. [Source and documentation](https://github.com/controlstackai-silicon/controlstackai-silicon.github.io). [Website](https://controlstackai-silicon.github.io/).

### ALINA NixOS v2

### ALINA SMS Policies

Public privacy and terms documents for ALINA SMS.

Status: Public source. [Source and documentation](https://github.com/ControlStackAI/alina-sms).

### ClawTerm

A Rust desktop client that turns tabs into persistent OpenClaw agent conversations instead of shell sessions.

Status: Prototype. [Source and documentation](https://github.com/ControlStackAI/clawterm). [Website](https://controlstackai.github.io/clawterm/).

### controlstackai-infra

Infrastructure source and deployment documentation, including placeholder applications.

Status: Public source. [Source and documentation](https://github.com/ControlStackAI/controlstackai-infra).

### controlstackai-site

Source for the ControlStackAI engineering-practice website and its API integration.

Status: Public source. [Source and documentation](https://github.com/ControlStackAI/controlstackai-site). [Website](https://controlstackai.com/).

### OpenClaw Topics

Reserved project for topic-based conversation switching. No plugin implementation is committed yet.

Status: Repository scaffold. [Source and documentation](https://github.com/ControlStackAI/openclaw-plugin-topics).

### Swarmdeck

A runtime-agnostic control plane for launching, supervising, and inspecting agent processes.

Status: Alpha. [Source and documentation](https://github.com/ControlStackAI/swarmdeck). [Website](https://controlstackai.github.io/swarmdeck/).

### Truss

Contract-driven agent execution with durable replay and signed evidence.

Status: Development. [Source and documentation](https://github.com/ControlStackAI/truss). [Website](https://controlstackai.github.io/truss/).

### gatekeeper-os

GatekeeperOS: capability-based access and deferred approvals for OpenClaw

Status: Public source. [Source and documentation](https://github.com/gatekeeper-os/gatekeeper-os).

### gatekeepers

Community gatekeepers for GatekeeperOS — capability-based access and deferred approvals for OpenClaw

Status: Public source. [Source and documentation](https://github.com/gatekeeper-os/gatekeepers).

### private-auth

Request-bound agent authorization using local Semaphore proofs and an Ethereum permission registry.

Status: Unaudited prototype. [Source and documentation](https://github.com/gatekeeper-os/private-auth). [Website](https://gatekeeper-os.github.io/private-auth/).

### Aircraft Analysis

MATLAB aircraft-analysis source and developer documentation, with project-specific resources and licensing.

Status: Public source. [Source and documentation](https://github.com/ManganoConsulting/Analysis).
